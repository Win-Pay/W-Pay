## Reused code

If code is adapted from another project (for example an earlier payment-gateway
prototype), keep that project's copyright header intact, add the original
licence notice, and record the source and commit here. W-Pay's own branding,
metadata and documentation are original; the repository contains no copied
project identity, logos or deployment claims.

## Icons and fonts

No third-party icon font is bundled. The UI uses system font stacks. The brand
mark is original CSS text, not a licensed image.
